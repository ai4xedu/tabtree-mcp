## The outline

This is the exact outline TabTree builds. Indentation is the hierarchy, and
`[ ]` marks a checkbox. You can paste it straight into TabTree, or into any
outliner that understands indentation.

```text
AI project — name
  Frame the problem
    The decision or task this must improve
    Who does it today, and how long it takes
    Baseline to beat — today's number, measured not guessed
    [ ] Success threshold agreed BEFORE building
    Out of scope
  Data and access
    Where the data lives, and who owns it
    [ ] Permission to use it confirmed
    [ ] Sensitive fields identified and handled
    Quality — what is missing, stale or wrong
  Build the POC
    The smallest version that proves the value
    Model and tools chosen — and why
    [ ] 20 real cases run end to end
    [ ] Result shown to someone who does the job
  Evaluate honestly
    [ ] Golden set of 30 cases with expected output
    Score on the golden set — the number
    Cost per run, and latency
    [ ] Compared against the baseline, not against zero
  Go / no-go
    What we do if it misses the threshold
    [ ] Decision written down, with the date
  Put it in production
    [ ] Human checkpoint wherever a mistake is costly
    [ ] Fallback when the model is slow or down
    [ ] Logging — inputs, outputs, corrections
    [ ] Owner named for the running system
  Run and improve
    Weekly review of failures
    [ ] Real failures added to the golden set
    Cost tracked monthly
```
