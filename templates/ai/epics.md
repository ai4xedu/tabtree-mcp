## The outline

This is the exact outline TabTree builds. Indentation is the hierarchy, and
`[ ]` marks a checkbox. You can paste it straight into TabTree, or into any
outliner that understands indentation.

```text
Project — feature name
  Context
    What we are building, and for whom
    Why now
    Technical constraints that must be respected
    Out of scope — what NOT to do
  Epic 1 — epic title
    US 1.1 — As a … I want … so that …
      [ ] Observable acceptance criterion
      [ ] Observable acceptance criterion
      Technical notes — files and functions involved
    US 1.2 — As a … I want … so that …
      [ ] Observable acceptance criterion
      Technical notes
  Epic 2 — epic title
    US 2.1 — As a … I want … so that …
      [ ] Observable acceptance criterion
      [ ] Observable acceptance criterion
  Definition of Done
    [ ] Tested — how we prove it
    [ ] Verified in the real app, not only in tests
    [ ] Documentation updated
  Risks and unknowns
    To settle BEFORE coding
    Assumption taken if nobody settles it
  Order of execution
    Where to start, and why
```
